## Run


This writes the epitaph to `/output/entry.txt` (override the output directory with the `MAKEFUN_OUTPUT_DIR` environment variable). The program verifies its own output before exiting: UTF-8, 1–150 characters, a single line, not only whitespace, and no trailing newline.
